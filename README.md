# 🛎 ВИТАЛИК — простое POS: зал → кухня → сводка

Мобильное PWA для ресторана в духе **Square KDS**: максимум простоты, ноль лишних кнопок.
Данные живут в **базе** (не в памяти серверной функции!) — заказы не пропадают и не мерцают.
Смартфоны опрашивают лёгкий `GET /api/sync` раз в **1.5 секунды**; обрыв 4G → тихий повтор через 1 секунду, без блокирующих экранов.

## Экраны (3 вкладки снизу)

| Экран | Что делает |
|---|---|
| 🛎 **Официант** | Кто ты (Саша/Денис/Вова, запоминается) · стол 1–12 · тумблер ⭐ВИП · меню по категориям (тап = +1 в корзину) · гарниры **прямо на карточке** горячего (+Картофель / +Соте / +Рис) · быстрые комментарии «Без лука» / «Детям» + свой текст · огромная зелёная кнопка «ОТПРАВИТЬ НА КУХНЮ (N блюд)» · лаконичные плашки «Стол 4 · Готовится 🔥» → «Стол 4 ГОТОВ К ВЫНОСУ! ✅» |
| 👨‍🍳 **Кухня** | **Сводка «что жарить сейчас»** (крупные счётчики: Ростбиф: 4, Брискет: 2, Картофель: 3…) · карточки заказов (возраст «4 мин», ВИП — золотая рамка, комментарий) · **одна кнопка** «✅ ГОТОВО К ВЫНОСУ» → карточка светится зелёным с крупным «📢 ЗАБРАТЬ СТОЛ № 3 (Саша)», повторный тап — в архив · 🔔 один «дзинь» на новый заказ (кнопка «Включить звук») · 🚫 стоп-лист в 1 клик |
| 📊 **Сводка** | Счётчик порций каждого блюда за смену · итоги · «Очистить смену» по PIN `0000` |

## Архитектура

```
Next.js 16 (App Router, TypeScript, Tailwind 4 + shadcn/ui)
├── /                 — единая страница-приложение (мобильный портрет, PWA)
├── GET  /api/sync    — лёгкий снапшот состояния (поллинг 1.5 с)
├── POST /api/orders  — create | ready | archive
├── POST /api/stoplist— вкл/выкл блюда
└── POST /api/reset   — очистка смены (PIN 0000)
```

**Хранение — Prisma + БД** (`Order`, `DishCounter`, `StopItem`). Никаких `let orders = []` в памяти лямбды —
статус заказов переживает рестарты и работает на нескольких устройствах одновременно.

## Запуск локально

```bash
npm install
npx prisma db push     # создать SQLite-базу из prisma/schema.prisma
npm run dev            # http://localhost:3000
```

## Деплой на Vercel (с постоянной БД)

1. Создайте бесплатную БД Postgres ([Supabase](https://supabase.com) или [Neon](https://neon.tech)) и скопируйте connection string.
2. В `prisma/schema.prisma` смените `provider = "sqlite"` → `provider = "postgresql"`.
3. В Vercel добавьте переменную `DATABASE_URL` = строка подключения.
4. Один раз выполните локально `DATABASE_URL="<строка>" npx prisma db push`.
5. Import репозитория на [vercel.com/new](https://vercel.com/new) — готово.

Синхронизация не зависит от WebSocket-серверов: обычные HTTP-запросы к `/api/*` работают на любом хостинге,
а Supabase Realtime при желании подключается поверх той же таблицы `Order`.

## Дизайн

Спокойный тёмный премиум: графит `#12141A`, карточки `#1A1E26`, границы `#2A2F3A`, белый текст,
изумруд готово `#10B981`, золото ВИП `#D4AF37`, красный стоп `#EF4444`. Все интерактивные плашки ≥50px под палец,
звук — один чёткий «дзинь» колокольчика (Web Audio, без файлов).
