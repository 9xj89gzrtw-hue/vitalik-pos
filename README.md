# 🛎 ВИТАЛИК — ресторанная POS-система

Мобильное PWA-приложение для ресторана: **зал ⇄ кухня ⇄ аналитика** на едином серверном состоянии. Никаких сокетов и экранов «Ждёт связи» — смартфоны официантов и шефа опрашивают сервер каждые **1.5 секунды** (Fast HTTP Polling), мутации уходят POST-запросами с идемпотентностью (`reqId`). Мигнул 4G — тихий повтор через 1 секунду, без блокирующих экранов.

## Экраны (3 вкладки снизу, 1 тап)

| Экран | Что делает |
|---|---|
| 🛎 **Официант** | Выбор официанта (Саша/Денис/Вова) и стола 1–12, ⭐ВИП-приоритет, комментарий к заказу («Детям вперёд», «После тоста»), меню Завтрак 10:00–12:00 / Обед 12:00–18:00, выбор гарнира к горячему, быстрые комментарии «Без лука»/«Без соуса» + свободный ввод, вкладка «Где мой заказ?» со статусом каждой порции, дозаказ |
| 👨‍🍳 **Шеф / Раздача** | Тревога нового заказа (циклический зуммер + мерцание до «ПРИНЯТЬ»), **Сводка цехов и Батчинг**: умная подсказка суфлера («Свободен Повар 2 → Озвучь 3× Ростбиф»), частичное озвучивание `[-] [Озвучить +N] [+]`, «Заказы по столам» с курсами и баннером **📢 ВЫНОС** для раннеров без телефонов, «Стоп-лист и остатки» с лимитами порций и автостопом на 0 |
| 📊 **Аналитика** | Точный счётчик приготовленных порций по каждому блюду, журнал закрытых чеков, сброс смены по PIN `0000` |

## 3 повара (цеха)

- **Повар 1 — Закуски и Десерты**: Сибас, Драники, Кокиль, Брауни, Слива, Чизкейк, Сырники
- **Повар 2 — Салаты и Завтрак**: Ростбиф, Свекла, Гравлакс, Каша, Омлет
- **Повар 3 — Горячее и Гарниры**: Утка, Брискет, Креветки, Картофель беби, Соте, Рис

## Архитектура

```
Next.js 16 (App Router, TypeScript, Tailwind 4 + shadcn/ui)
├── /                — единая страница-приложение (мобильный портрет, PWA)
├── GET  /api/sync   — полное состояние (поллинг 1.5 с)
├── POST /api/orders — create | acknowledge | announce | ready | served
├── POST /api/stoplist — setStopped | setLimit
└── POST /api/reset  — сброс смены (PIN 0000)
```

Состояние живёт в серверном in-memory сторе (`src/lib/server-store.ts`, `globalThis`) — единый источник истины для всех устройств. Модель порций: `queued → cooking → ready → served` со счётчиками на каждой позиции (частичное озвучивание и частичный вынос).

## Запуск

```bash
bun install        # или npm install
bun run dev        # http://localhost:3000
```

Продакшен: `npm run build && npm start` (standalone) или деплой на Vercel — `vercel --prod`.

Переменные окружения не требуются.
